lwl，团队参赛。
团队：MCN-ship（团队 ID 1404510）。成员：nick5346082023-11968（lwl）、nick9531986463-30392、nick9495126920-42809。

我每天和 AI 聊写代码、调 bug、讨论方案。十几轮聊完，bug 修好了，但我记不清是哪一轮让我换了思路、哪句话推翻了我先前的假设。聊天记录翻不动，也翻不出来。
我想要的不是一个事后总结，而是**在想法被推翻、合并、转向的当下，就在图上留下痕迹**，日后能回看自己是怎么想的。
所以我做了「思维星图 / Thought Atlas」：**一个跑在你自己电脑上的复盘插件**。它只读接上你日常开发用的 agent（Codex / Qoder），把每轮真实对话里你的想法提取成节点，长在同一张星图上。聊完回头看，不是一堆聊天记录，是你自己思路的变化轨迹。
在线站点是同一引擎的免门槛体验窗口：回放样例与限量沙箱，让你先看见图怎么长，再决定要不要装。

### 我真正想用它做什么

- 调 bug 十几轮之后回看：是哪一轮让我放弃了原假设，AI 的哪句话把我推过去的。
- 长方案讨论里看清自己采纳了哪些观点、放弃了哪些、妥协落在哪一轮。
- 隔一周再打开这张图：我对这个模块、这个问题的理解，已经和上周不一样了。

用法：源码在 GitHub 自取（【GitHub 仓库链接（作者上传后填）】，仓库名 thought-atlas），一条 `./setup.sh` 装依赖、构建、生成 600 权限配置模板（Key 只存你本机，脚本不碰已有配置）；填上你自己的 Key 启动守护进程即可。只读轮询 Codex / Qoder 的会话文件，不修改 agent 的任何文件；原文只留本机，没有轮数限制。

### 想先看看它怎么长图（在线）

在线体验：https://thought-atlas-njl1tep74um.qoder.zone/

1. **看一段回放**。样例是一段「毕业先工作还是读研」的决策对话：10 轮聊出 9 个节点、1 次立场转折，节点沿时间脊柱排开，带步序号与「起点」徽标，转向节点是琥珀色。首页星图会自动从第 1 轮生长到最后一轮。样例是合成演示数据，页面有明确标注。
2. **亲手聊一段**（在线沙箱）。接真实模型（DeepSeek），不是假回复。左边聊天，右边星图实时生长；点节点看它诞生于第几轮、被谁影响/取代。聊完一键导出 PNG 分享卡——只含节点级摘要，不含对话原文。

### 两条我特意做死的边界

- **原文不落库。** 服务端只存节点级摘要和事件流，对话原文分析完即弃；验收脚本里有哈希比对断言，库里搜不到你输入的原句。
- **限额是硬的。** 沙箱每 IP 每日 2 次会话、单会话 15 轮、全站每日 100 次分析，超了直接 429，不是前端装样子。为什么这么抠：比赛期间用的是我自己的 API 额度，得让每个来试的同学都聊得上。

### 一点实现上的取舍（给想看的同学）

- 图不是力导向乱飘：语义边连通分量算「站点」，站点按时间走蛇形脊柱，站内叶序螺旋。缩放时图层分级淡出，缩远了看结构、拉近了看单星。
- 分析端「宁可少拿」：模型没把握的节点/边直接不画，不凑数。所以样例图干净，不是渲染偷懒。
- 转向（shift）是一等公民：单独节点类型 + 琥珀色 + 「触发于第 N 轮」，这是整个产品最想让你看见的东西。

### Known limits（不藏）

- 公开样例全部合成，真实会话样例未获授权公开，就不放。
- 沙箱是体验额度，重度使用请装本地版。
- 键盘选节点、更多聊天工具适配器、周回顾，赛后再做。

代码与证据链都在仓库里，欢迎拍砖。
